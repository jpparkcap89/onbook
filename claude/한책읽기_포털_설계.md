## 1. 목표

- 박선영 작가의 동화 3권을 학년군별로 함께 읽는 **한 책 읽기 포털**
- 책마다 **10차시 학생 활동 + 활동지**(학습지·만들기·쓰기·놀이를 골고루)
- 학생이 감상·질문·작품을 **온라인으로 제출**하고, 교사가 확인·공개
- **박선영 작가 소개 페이지** 포함
- 디자인: cap89 스타일(파스텔 블롭 배경, 유리 카드, Pretendard, 블루 프라이머리)

| 학년군 | 도서 | 정보 |
|---|---|---|
| 1~2학년 | 가비와 달랑달랑 달랑구 | 박선영 글 · 유석 그림 · 별빛서재(도담소리) · 2024 · 84쪽 |
| 3~4학년 | 꿈의 공책 | 박선영 글 · 한혜정 그림 · 도담소리 · 2026 · 104쪽 |
| 5~6학년 | 도와줘! 예비 천사 한수이 | 박선영 글 · 채인화 그림 · 고래책빵 · 2025 · 112쪽 (평택시문화재단 2025 전문예술활동 지원사업 선정작) |

> 저작권: 포털에는 본문을 길게 옮기지 않는다. 활동에 꼭 필요한 짧은 구절만 쪽수와 함께 넣는다.

## 2. 시스템 구조

```
[학생·교사 브라우저]
      │
      ▼
GitHub Pages (프론트엔드, 정적 HTML/CSS/JS)
      │  fetch (GET: 조회 / POST: text/plain 으로 제출 → CORS preflight 회피)
      ▼
Google Apps Script 웹앱 (백엔드 API, doGet / doPost)
      │
      ▼
Google Sheets (데이터베이스)
```

- **프론트**: GitHub 저장소(가칭 `jpparkcap89/onebook`) → GitHub Pages 배포
- **백엔드**: GAS 웹앱 — 실행 계정: 나, 액세스: 모든 사용자. `clasp`로 로컬에서 push/deploy
- **DB**: 구글 시트 1개(탭 여러 개)
- 활동 콘텐츠는 `data/books.json`(저장소)에 두고, 교사가 시트에서 고친 내용이 있으면 우선 적용(선택 기능)

### 저장소 폴더 구조(안)
```
onebook/
├─ index.html            # 홈 + 라우팅(#gabi, #gabi-3, #author …)
├─ assets/style.css
├─ assets/app.js
├─ data/books.json       # 책·차시·활동지 문항
├─ gas/Code.gs           # Apps Script 백엔드
├─ gas/appsscript.json
├─ .clasp.json           # scriptId (커밋 여부 결정 필요)
└─ README.md
```

## 4. 구글 시트 구조

**탭 `submissions`** (학생 제출)
| 열 | 설명 |
|---|---|
| id | UUID |
| createdAt | 제출 시각 |
| bookId | gabi / dream / suii |
| lesson | 1~10 |
| grade, classNo, studentNo | 학년, 반, 번호 |
| nickname | 공개용 이름(선택, 기본은 "3반 12번") |
| type | 감상 / 질문 / 작품 / 활동지 |
| content | 본문 |
| imageUrl | (선택) 작품 사진 — 드라이브 업로드 시 |
| status | 대기 / 공개 / 숨김 |
| teacherComment | 교사 댓글 |

**탭 `classes`**: 학년, 반, 담임 이름, 담임 이메일, 반 코드(학생 제출용 간단 코드)
**탭 `settings`**: 교사 관리 코드(실제 값은 Script Properties에 저장), 공개 기본값(승인제 on/off)
**탭 `lessons`**(선택): 교사가 활동 문구를 고칠 때 덮어쓰기용

### 개인정보 원칙
- 실명 입력 받지 않음(학년·반·번호 + 선택 닉네임)
- 기본값은 **교사 승인 후 공개**
- 게시판에는 반·번호 또는 닉네임만 노출

## 5. GAS API 명세(안)

| 메서드 | action | 파라미터 | 응답 |
|---|---|---|---|
| GET | `posts` | bookId, lesson?, grade?, classNo? | 공개된 제출물 목록 |
| GET | `lessons` | bookId | 시트 덮어쓰기 내용(있을 때) |
| POST | `submit` | bookId, lesson, grade, classNo, studentNo, nickname, type, content, classCode | `{ok, id}` |
| POST | `admin.list` | adminCode, filters | 전체 제출물 |
| POST | `admin.update` | adminCode, id, status, teacherComment | `{ok}` |

- POST 본문은 JSON 문자열을 `Content-Type: text/plain`으로 전송
- 입력 길이 제한(예: 2000자), HTML 이스케이프, 반 코드 확인, 같은 번호 연속 제출 간격 제한
- 관리 코드는 `PropertiesService.getScriptProperties()`에 보관

## 6. 박선영 작가 소개 페이지(초안 구성)

**확인된 내용(책에서)**
- 《가비와 달랑달랑 달랑구》 작가의 말: 선생님으로 지내며 말썽꾸러기처럼 보이던 아이들도 일부러 그러는 게 아니라는 것을 알게 되었다는 이야기, 친구들 눈높이에서 들어 주고 기다려 주자는 당부, 1학년의 "시작을 응원"하는 마음
- 《꿈의 공책》 작가의 말 「마음에 작은 등불을 켜 보세요」: 공책에 마음을 적다 보면 내 안의 목소리가 들린다, 서툴러도 넘어져도 괜찮다
- 《도와줘! 예비 천사 한수이》 작가의 말 「용기의 꽃가루를 선물하며」: 남과 비교하지 않고 나를 있는 그대로 사랑하는 용기, 고맙다·미안하다·아니라고 말하는 용기

**페이지 구성**
1. 작가 한 줄 소개 + 사진(허락 받은 경우)
2. 작가가 아이들에게 전하는 세 가지 메시지(책별 작가의 말 요약 카드)
3. 작품 목록(세 권 + 다른 작품)
4. 작가에게 묻고 싶은 질문 모으기(학생 질문 → 작가와의 만남 행사 때 활용)

**작가님께 받아야 할 것(⚠️ 미확인 — 지어내지 않음)**
- [ ] 약력(출생지, 등단, 수상, 활동)
- [ ] 다른 작품 목록
- [ ] 사진·책 표지 이미지 사용 허락
- [ ] 학생들에게 전하는 인사말(선택)

### 7-1. 가비와 달랑달랑 달랑구 (1~2학년)

**줄거리 요약**: 1학년 1반에 입학한 가비는 궁금한 것이 많고 달리기를 좋아하지만, 선생님 말을 끊거나 줄을 벗어나 자주 주의를 듣는다. 유치원 친구 서진이는 가비를 '까비'라고 부르며 놀린다. 하굣길 인형뽑기 기계에서 팔이 긴 토끼 인형을 뽑아 '달랑구'라 이름 짓는데, 달랑구는 가비하고만 말을 한다. 달랑구는 가비의 마음을 들어 주다가, 어느 날은 가비의 말투를 흉내 내며 가비가 입장을 바꿔 생각하게 돕는다. 효은이에게 벚꽃잎을 건네고 서진이와 준비물을 나누며 친구가 생긴 날, 달랑구는 가방에서 사라지고 다른 아이의 가방에 매달려 멀어진다.

| 차시 | 범위 | 활동명 | 유형 | 활동 내용 |
|---|---|---|---|---|
| 1 | 표지·제목 | 달랑달랑 흉내 말 놀이 | 🎲📝 | 표지 보고 이야기 상상하기, '달랑달랑·콩당콩당·뽀드득' 같은 흉내 말을 몸으로 표현하는 놀이, 달랑구는 누구일지 예측 |

### 7-2. 꿈의 공책 (3~4학년)

**줄거리 요약**: 5학년 박주하는 3학년 2학기부터 바이올린을 배워 콩쿠르를 준비하지만, 매일 두 시간 연습에 지쳐 친구들과 놀 시간이 없다. 육상 국가대표가 꿈인 전학생 수연이는 늘 공책에 생각을 적는다. 선생님 깜짝 생일 파티에서 주하는 반주를 맡아 처음으로 '바이올리니스트가 되고 싶다'고 느끼지만, 아빠가 일자리를 잃은 것을 엿듣고 콩쿠르와 바이올린을 그만두겠다고 말한다. 수연이가 건넨 서류봉투 속 '물음표 공책'과 편지(편지는 사라짐), 선주 언니의 말, 수학 학원 기초반의 경험을 지나 주하는 학교 오케스트라 연주를 듣고 진짜 하고 싶은 것을 깨닫는다. 엄마에게 솔직하게 말하고 오케스트라에 다시 들어가며, 공책 제목을 다시 쓴다. 에필로그에서 아빠가 서랍에 넣어 둔 편지를 찾고, 주하는 친구 미나에게 공책을 선물한다.

### 7-3. 도와줘! 예비 천사 한수이 (5~6학년)

**줄거리 요약**: 서천꽃밭에서 몸(구름 타기)·마음(꽃밭 가꾸기)·지혜(구름 설계) 수련을 받는 꽃밭둥이 한수이는 질문 많고 아이디어가 넘치지만 쉽게 싫증 낸다. 하늘차사의 갓으로 변신해 올라온 도깨비 용달이에게 '그멈땡' 기술을 배우느라 수련을 게을리하고 거짓말까지 한 사실이 드러나, 꽃감관 한락궁이에게 벌을 받을 처지가 된다. 한수이는 용달이를 땅세상에 데려다주고 내리초 4학년 1반 이세인을 삼칠일(21일) 안에 돕겠다고 나선다(세 가지 약속: 투시력은 한 번만, 정체 숨기기, 기한 지키기). 전학생이 된 한수이는 아는 것이 많아 '잘난 척 대장'으로 미움받는 세인이와, 엄마에게 늘 세인이와 비교당하는 준환이를 만난다. 지쳐 포기하려던 순간 용달이와 화해하고, 한수이의 눈물로 살아난 배려꽃·용기꽃으로 두 친구의 마음을 움직인 뒤 서천꽃밭으로 돌아간다.
